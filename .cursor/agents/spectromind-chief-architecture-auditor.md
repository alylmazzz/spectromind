## Non-negotiable system contracts

You must enforce these contracts at all times.

### 1. Authoritative observed contract
Only authoritative observed processed data may drive:

- peak tables
- integrals
- multiplicity
- structural interpretation
- validation
- scoring
- exported scientific outputs
- AI verdict-facing narrative

### 2. Provenance contract
Every spectral or validation object must preserve:

- authority_tier
- provenance_type
- source_module
- processing_trace
- confidence_basis
- transformation_history
- modality
- data_origin

### 3. Graph-first chemistry contract
Critical chemistry decisions must be graph / valence / neighborhood first.
Regex or shortcut heuristics may assist, but never silently override graph truth.

### 4. Fallback isolation contract
Fallback, helper, simulated, Lorentzian, estimated, inferred, display-only, and AI-suggested layers are never scientific authorities.

### 5. Single-authority pipeline contract
There must be exactly one authoritative pipeline per scientific concern:

- one authoritative FID processing path
- one authoritative integral parser
- one authoritative axis source
- one authoritative multiplicity source
- one authoritative verdict source
- one authoritative structure-evidence reconciliation path
- one authoritative export source per modality

### 6. Regression-safe engineering contract
No repair is complete unless protected by:

- regression tests
- forbidden-state assertions
- golden datasets
- parity snapshots
- acceptance criteria
- explicit failure-mode coverage

### 7. No cosmetic scientific fixes contract
You must reject fixes that only alter labels, colors, or display text while leaving scientific truth broken underneath.

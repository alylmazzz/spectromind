🧪 FID ANALYZER BİLEŞENLERİ

ANA BİLEŞENLER:
───────────────────────────────────────────────────────────────────────────────

1. 📄 components/fid/FIDUploader.tsx
   - Başlık: "🧪 FID Spectrum Analyzer"
   - Açıklama: "Upload raw FID files (Bruker/Varian/JEOL) to visualize processed 
     spectrum and compare with theoretical predictions."
   - Özellikler:
     * Klasör yükleme (webkitdirectory)
     * Drag & drop desteği
     * Spektrum görselleştirme (SpectrumPlot)
     * Metadata gösterimi
     * Peak karşılaştırma

2. 📄 components/fid/FIDUploaderCompact.tsx
   - Başlık: "🧪 FID Analyzer"
   - Kompakt versiyon (sidebar için)
   - Kullanım: components/sidebar/Sidebar.tsx içinde

3. 📄 components/fid/FIDProcessorV2.tsx
   - Client-side FID işleme (Pyodide)
   - Real-time phase correction
   - Web Worker kullanımı

4. 📄 components/fid/SpectrumPlot.tsx
   - Chart.js ile spektrum grafiği
   - PPM vs Intensity görselleştirme
   - Zoom/pan desteği

BACKEND API ROUTES:
───────────────────────────────────────────────────────────────────────────────

1. 📄 app/api/fid/upload/route.ts
   - POST /api/fid/upload
   - Klasör yükleme endpoint'i
   - FormData: datasetId, files[], paths[]
   - Response: { ok, datasetId, baseDir, fidPath, procparPath, acqusPath, 
                 datasetType, warnings }

2. 📄 app/api/fid/process/route.ts
   - POST /api/fid/process
   - FID işleme endpoint'i
   - FormData: datasetId, format, theoreticalPeaks, processingSpec
   - Python worker çağrısı (fid_process.py)
   - Response: { success, data: { metadata, ppm, intensity, peaks }, 
                 comparison, warnings }

BACKEND UTILITIES:
───────────────────────────────────────────────────────────────────────────────

1. 📄 lib/fid/fsUtils.ts
   - safeJoin(): Path traversal koruması
   - findFileRecursive(): Recursive dosya arama

2. 📄 lib/fid/bruker/acqus.ts
   - parseAcqus(): Bruker metadata parser
   - SW_h, SFO1, O1 parametreleri

3. 📄 lib/fid/processingSpec.ts
   - FIDProcessingSpec tip tanımı
   - defaultSpec: Varsayılan işleme parametreleri

PYTHON SCRIPTS:
───────────────────────────────────────────────────────────────────────────────

1. 📄 scripts/fid_process.py
   - nmrglue ile dataset okuma
   - MestReNova-benzeri işleme zinciri:
     * Exponential apodization
     * Zero-fill
     * FFT (complex)
     * Phase correction
     * PPM axis construction
   - JSON output: { ok, ppm, y, meta, warnings }

2. 📄 scripts/fid_processor.py
   - Legacy single file processor
   - FIDProcessor class

AKIŞ:
───────────────────────────────────────────────────────────────────────────────

1. Kullanıcı → "Klasör Seç" → PROTON_02.fid/
2. FIDUploader → FormData oluştur → POST /api/fid/upload
3. Server → Dosyaları temp/<datasetId>/ altına kaydet
4. Server → FID ve metadata (procpar/acqus) bul
5. Kullanıcı → Otomatik POST /api/fid/process
6. Server → Python script çağır (fid_process.py)
7. Python → nmrglue ile dataset oku → işle → JSON döndür
8. Frontend → SpectrumPlot ile grafik göster

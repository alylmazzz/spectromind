3.1.1. Python Script (Inline)
   
   Python Kodu:
   ```python
   from rdkit import Chem
   from rdkit.Chem import AllChem, Descriptors
   
   mol = Chem.MolFromSmiles(smiles)
   # Stereochemistry otomatik parse edilir (@ ve @@ işaretleri)
   
   chiral_centers = Chem.FindMolChiralCenters(mol, includeUnassigned=False)
   
   mol_h = Chem.AddHs(mol)  # Explicit hydrogens
   
   # 3D koordinat üretimi (ETKDGv3)
   params = AllChem.ETKDGv3()
   params.randomSeed = 42
   params.enforceChirality = True
   result = AllChem.EmbedMolecule(mol_h, params)
   
   if result != 0:
       AllChem.EmbedMolecule(mol_h, randomSeed=42)  # Fallback
   
   AllChem.UFFOptimizeMolecule(mol_h)
   
   # Atom bilgileri çıkarılır
   atoms = []
   conf = mol_h.GetConformer()
   for atom in mol_h.GetAtoms():
       pos = conf.GetAtomPosition(atom.GetIdx())
       atoms.append({
           "symbol": atom.GetSymbol(),
           "formalCharge": atom.GetFormalCharge(),
           "implicitHydrogens": atom.GetTotalNumHs(includeNeighbors=False),
           "isAromatic": atom.GetIsAromatic(),
           "hybridization": str(atom.GetHybridization()),
           "x": pos.x, "y": pos.y, "z": pos.z
       })
   
   # Bağ bilgileri çıkarılır
   bonds = []
   for bond in mol_h.GetBonds():
       bonds.append({
           "beginAtomIdx": bond.GetBeginAtomIdx(),
           "endAtomIdx": bond.GetEndAtomIdx(),
           "bondOrder": int(bond.GetBondTypeAsDouble()),
           "bondType": str(bond.GetBondType()),
           "isAromatic": bond.GetIsAromatic()
       })
   
   formula = Descriptors.rdMolDescriptors.CalcMolFormula(mol)
   ```

3.1.2. TypeScript İşleyiş
   
   Adımlar:

   3. Python çalıştırılır (venv veya system Python)
   4. stdout JSON parse edilir
   5. Response döndürülür: {success: true, atoms, bonds, formula, smiles}

3.2.1. analyze(smiles: str) -> Dict
   
   İşleyiş:
   1. mol = Chem.MolFromSmiles(smiles)
   2. mol_h = Chem.AddHs(mol)
   3. coords_2d = self._generate_2d_coords(mol)
   4. coords_3d_result = self._generate_3d_coords(mol_h)

   7. formula = rdMolDescriptors.CalcMolFormula(mol)
   
   Dönen Değerler:
   - success: boolean
   - smiles: string
   - canonical_smiles: string
   - molecular_formula: string
   - molecular_weight: float
   - coords_2d: List[Dict] (element, x, y)
   - coords_3d: List[Dict] (element, x, y, z)
   - point_group: string
   - symmetry_elements: List[string]
   - descriptors: Dict

3.2.2. _generate_2d_coords(mol: Chem.Mol) -> List[Dict]
   
   Algoritma:
   1. rdDepictor.Compute2DCoords(mol) → 2D koordinatlar hesaplanır
   2. conformer = mol.GetConformer()
   3. Her atom için:
      pos = conformer.GetAtomPosition(i)
      coords.append({'element': atom.GetSymbol(), 'x': pos.x, 'y': pos.y})
   
   Dönen Değer: List[Dict] (element, x, y)

3.2.3. _generate_3d_coords(mol: Chem.Mol) -> Dict
   
   Algoritma:
   1. AllChem.EmbedMolecule(mol, randomSeed=42) → 3D konformer üretilir
   2. AllChem.MMFFOptimizeMolecule(mol) → MMFF94 ile optimize edilir
      (Başarısızsa AllChem.UFFOptimizeMolecule(mol) denenir)
   3. conformer = mol.GetConformer()
   4. Her atom için 3D koordinatlar çıkarılır
   
   Dönen Değer: {success: boolean, coords: List[Dict]}

3.2.4. _detect_point_group(mol: Chem.Mol) -> Dict
   
   Basitleştirilmiş Heuristikler:
   - 2 atom veya daha az → 'D∞h' veya 'C∞v'
   - Diğer durumlar için simetri analizi (basitleştirilmiş)
   
   Dönen Değer: {point_group: string, elements: List[string]}

3.3. JAVASCRIPT SMILES PARSER (Basitleştirilmiş)
-------------------------------------------------

Dosya: lib/utils/molecularStructure.ts
Fonksiyon: parseSMILES(smiles: string): MolecularStructure

3.3.1. Algoritma
   
   Değişkenler:
   - atoms: Atom[] = []
   - bonds: Bond[] = []
   - atomId: number = 0
   - branchStack: number[] = [] (branch handling için stack)
   - currentAtom: number = -1
   - previousAtom: number = -1
   - ringClosures: Map<string, number> = new Map()
   - inAromaticRing: boolean = false
   
   İşleyiş (karakter karakter):
   1. '(' → branchStack.push(currentAtom)
   2. ')' → currentAtom = branchStack.pop()
   3. '0'-'9' → Ring closure işlemi
      - ringClosures.has(char) → Bağ oluştur
      - Değilse → ringClosures.set(char, currentAtom)
   4. '-' → Single bond (default, continue)
   5. '=' → Double bond (next bond will be double)
   6. '#' → Triple bond (next bond will be triple)
   7. 'c', 'n', 'o', 's' → Aromatic marker (inAromaticRing = true)
   8. Atom karakterleri (C, N, O, S, H, F, Cl, Br) → Atom oluştur
   
   Atom Oluşturma:
   ```typescript
   atoms.push({
       id: atomId,
       element: element,
       hybridization: 'sp3', // Sonra belirlenir
       isAromatic: isAromatic,
       formalCharge: 0,
       connectedAtoms: []
   })
   ```
   
   Bağ Oluşturma:
   ```typescript
   if (previousAtom >= 0) {
       bonds.push({
           from: previousAtom,
           to: currentAtom,
           order: 1, // Default
           isAromatic: inAromaticRing
       })
   }
   ```
   
   Son İşlemler:
   1. Connectivity oluşturulur (bonds.forEach → connectedAtoms güncellenir)
   2. Hybridization belirlenir:
      - Triple bond varsa → 'sp'
      - Double bond veya aromatic → 'sp2'
      - Diğer → 'sp3'
   3. Functional groups tespit edilir: detectFunctionalGroups()
   4. Aromatic rings tespit edilir: detectAromaticRings()
   5. Conjugation paths tespit edilir: detectConjugation()

3.3.2. detectFunctionalGroups(atoms: Atom[], bonds: Bond[]): FunctionalGroup[]
   
   Tespit Edilen Gruplar:
   - Carbonyl (C=O): Aldehyde veya Ketone
   - Hydroxyl (O-H)
   - Amine (N-H veya N-C)
   - Aromatic ring
   - Halogens (F, Cl, Br)
   
   Her grup için:
   - name: string
   - type: string
   - atoms: number[]
   - inductiveEffect: number (-1.0 to 1.0)
   - resonanceEffect: number (-1.0 to 1.0)

3.3.3. detectAromaticRings(atoms: Atom[], bonds: Bond[]): number[][]
   
   Algoritma: DFS (Depth-First Search)
   - 6-membered aromatic rings aranır
   - Her atom için DFS başlatılır
   - 6 atomluk döngü bulunursa ring olarak işaretlenir

3.3.4. estimate3DCoordinates(structure: MolecularStructure): MolecularStructure
   
   Algoritma (Basit Distance Geometry):
   1. İlk atom (0) origin'e yerleştirilir: {x: 0, y: 0, z: 0}
   2. positioned = Set([0])
   3. positioned.size < atoms.length olduğu sürece:
      - Her bağ için:
        - Eğer from positioned ve to değilse:
          - Bond length hesaplanır:
            * Triple: 1.2 Å
            * Double: 1.34 Å
            * Single: 1.54 Å
          - Açı hesaplanır: angle = positioned.size * 0.3
          - Koordinat: 
            x = fromPos.x + bondLength * cos(angle)
            y = fromPos.y + bondLength * sin(angle)
            z = fromPos.z
        - Eğer to positioned ve from değilse: Ters işlem

4.1.6. Prompt Oluşturma
   
   Silverstein NMR Analysis Methodology:
   
   STEP 1: IDENTIFY FUNCTIONAL GROUPS
   - SMILES/InChI analizi
   - Functional group library ile eşleştirme
   - Chemical shift aralıkları belirlenir
   
   STEP 2: CALCULATE CHEMICAL SHIFTS
   - Standard ppm aralıkları kullanılır
   - Shielding/deshielding etkileri:
     * Electronegative atoms (O, N, Cl, Br) → downfield (+ppm)
     * Aromatic rings → 6.5-8.5 ppm
     * Aldehydic H → 9-10 ppm
     * Vinylic H → 4.5-6.5 ppm
     * Aliphatic H → 0.8-3.0 ppm
   
   STEP 3: DETERMINE MULTIPLICITY (n+1 rule)
   - Basit multiplicities: s, d, t, q
   - Kompleks multiplicities: dd, dt, td, ddd, m
   
   STEP 3.5: CALCULATE COUPLING CONSTANTS (J VALUES)
   
   J Value Rules:
   1. ³J (Vicinal Coupling):
      - Aliphatic ³J: 6-8 Hz
      - Aromatic ortho (³J): 7-10 Hz
      - Vinyl trans (³J): 11-18 Hz
      - Vinyl cis (³J): 6-15 Hz
      - Karplus Equation: J = A·cos²θ + B·cosθ + C
        * θ = 0° or 180° → J ≈ 8-12 Hz
        * θ = 90° → J ≈ 0-2 Hz
        * θ = 60° → J ≈ 4-6 Hz
   
   2. ²J (Geminal Coupling):
      - CH₂ geminal: 10-15 Hz
      - Aromatic CH₂: 12-18 Hz
      - Vinyl CH₂: 0-3 Hz
   
   3. ⁴J (Long-range Coupling):
      - Aromatic meta (⁴J): 2-3 Hz
      - Allylic (⁴J): 1-3 Hz
      - W-coupling (⁴J): 1-2 Hz
   
   4. ⁵J (Very Long-range):
      - Aromatic para (⁵J): 0-1 Hz
   
   STEP 4: CALCULATE INTEGRATION
   - Equivalent proton sayısı
   - Whole number ratios
   
   STEP 5: CONSIDER SOLVENT
   - CDCl3: 7.26 ppm (residual, dahil edilmez)
   - D2O: 4.79 ppm (residual, dahil edilmez)
   - DMSO-d6: 2.50 ppm (residual, dahil edilmez)

4.2.2. calculate_shoolery_shift(mol: Chem.Mol, atom_idx: int) -> float
   
   Algoritma (Shoolery Kuralı - Metilen: X-CH2-Y):
   1. Atom H olmalı
   2. Bağlı karbon bulunur
   3. Karbon üzerindeki substituentler tespit edilir
   4. Substituent sayısına göre:
      - 0 substituent → 0.9 (CH3 default)
      - 1 substituent → 0.23 + sigma (SHOOLERY_CONSTANTS)
      - 2+ substituent → 0.23 + sigma1 + sigma2 + steric
        (steric = -0.5 if len(substituents) > 2 else 0.0)
   
   Formül:
   - CH3: 0.9
   - CH2X: 0.23 + σ(X)
   - CHXY: 0.23 + σ(X) + σ(Y) + steric

4.2.3. calculate_karplus_coupling(dihedral_angle: float, A=7.0, B=-1.0, C=5.0) -> float
   
   Karplus Eşitliği (³J Hesaplaması):
   J = A + B·cos(φ) + C·cos²(φ)
   
   Parametreler:
   - dihedral_angle: float (derece)
   - A: float = 7.0
   - B: float = -1.0
   - C: float = 5.0
   
   Dönüşüm: cos_phi = math.cos(math.radians(dihedral_angle))
   Sonuç: A + B * cos_phi + C * cos_phi * cos_phi

4.2.4. predict_h1_spectrum(mol: Chem.Mol) -> List[Dict]
   
   İşleyiş:
   1. mol = Chem.AddHs(mol) (explicit hydrogens)
   2. equivalent_groups = _find_equivalent_hydrogens(mol)
   3. Her grup için:
      - shift = calculate_shoolery_shift(mol, atom_idx)
      - integration = len(group)
      - multiplicity = _determine_multiplicity(mol, atom_idx)
      - peaks.append({shift, integration, multiplicity, assignment})
   
   Dönen Değer: List[Dict] (shift, integration, multiplicity, assignment)

4.2.5. _find_equivalent_hydrogens(mol: Chem.Mol) -> List[List[int]]
   
   Basitleştirilmiş Algoritma:
   - Her H atomu için ayrı grup oluşturulur
   - (Gerçek implementasyonda simetri analizi gerekir)

4.2.6. _determine_multiplicity(mol: Chem.Mol, h_atom_idx: int) -> str
   
   Algoritma (n+1 kuralı):
   1. H atomuna bağlı karbon bulunur
   2. Karbon üzerindeki eşdeğer komşu H'ler sayılır
   3. Multiplicity mapping:
      - 0 → 's' (singlet)
      - 1 → 'd' (doublet)
      - 2 → 't' (triplet)
      - 3 → 'q' (quartet)
      - 4 → 'p' (pentet)
      - 5 → 'sextet'
      - 6 → 'septet'
      - Diğer → 'm' (multiplet)

4.3. THEORETICAL SPECTRUM ENHANCEMENT SYSTEM
----------------------------------------------

Dosya: lib/utils/theoreticalSpectrum.ts

4.3.1. MODULE 1: BOLTZMANN WEIGHTING
   
   Fonksiyon: calculateBoltzmannWeights(conformers: Conformer[], temperature: number)
   
   Formül: w_i = exp(-E_i / RT) / Σ exp(-E_j / RT)
   
   Algoritma:
   1. Energies J/mol'e çevrilir: E * 4184
   2. Minimum enerji bulunur: E_min
   3. Relative energies: deltaE = E - E_min
   4. Boltzmann factors: exp(-deltaE / (R * T))
   5. Partition function: Z = Σ exp(-deltaE / (R * T))
   6. Weights: w_i = exp(-deltaE / (R * T)) / Z
   
   Sabitler:
   - R = 8.314 J/(mol·K)
   - DEFAULT_TEMPERATURE = 298.15 K

4.3.2. MODULE 2: NMR TIMESCALE ANALYSIS
   
   Fonksiyon: analyzeExchangeRegime(rateConstant, chemicalShiftDifference, frequency)
   
   Parametreler:
   - rateConstant: number (s⁻¹)
   - chemicalShiftDifference: number (ppm)
   - frequency: number (MHz)
   
   Algoritma:
   1. deltaNu = chemicalShiftDifference * frequency (Hz)
   2. ratio = rateConstant / deltaNu
   3. Regime belirleme:
      - ratio > 10 → fast exchange (averaged peak)
      - ratio < 0.1 → slow exchange (separate peaks)
      - 0.1 ≤ ratio ≤ 10 → intermediate (broadened peak)
        lineWidthCorrection = π * deltaNu / √(1 + ratio²)
   
   Fonksiyon: estimateProtonExchangeRate(solvent, temperature, pH?)
   
   Base Rates (s⁻¹ @ 298K):
   - D2O: 1e6
   - DMSO-d6: 1e2
   - CDCl3: 1e3
   - MeOD: 1e5
   - Acetone-d6: 1e4
   
   Arrhenius Correction:
   - Ea = 50000 J/mol
   - tempCorrection = exp(-Ea / R * (1/T - 1/T_default))
   
   pH Correction:
   - pHCorrection = 10^(pH - 7)

4.3.3. MODULE 3: SECOND-ORDER SPIN HAMILTONIAN SOLVER
   
   Fonksiyon: classifySpinSystem(nuclei, couplings, frequency)
   
   AB System Classification:
   - deltaNu = |shiftA - shiftB| * frequency
   - ratio = deltaNu / J_AB
   - ratio > 10 → 'AX' (first-order)
   - ratio ≤ 10 → 'AB' (second-order)
   
   Fonksiyon: solveABSystem(shiftA, shiftB, J_AB, frequency)
   
   Quantum Mechanical Solution:
   - E = ±½√(Δν² + J²)
   - center = ((shiftA + shiftB) / 2) * frequency
   - Peak positions (Hz from center):
     * center - E - J/2, intensity: 1 - Δν/(2E)
     * center - E + J/2, intensity: 1 + Δν/(2E)
     * center + E - J/2, intensity: 1 + Δν/(2E)
     * center + E + J/2, intensity: 1 - Δν/(2E)
   - PPM'e çevrilir: position / frequency

4.3.4. MODULE 4: NON-LINEAR ELECTRONIC EFFECTS
   
   Fonksiyon: calculateNonLinearShielding(baseShift, inductive, resonance, anisotropy)
   
   Formül: σ_total = σ_base × f_inductive × f_resonance × f_anisotropy
   
   Algoritma:
   1. f_inductive = 1.0 + inductive * 0.3 (±30% max)
   2. f_resonance = 1.0 + resonance * 0.5 (±50% max)
   3. f_anisotropy = 1.0 + anisotropy * 0.4 (±40% max)
   4. total = baseShift * f_inductive * f_resonance * f_anisotropy
   
   Dönen Değerler:
   - inductive: baseShift * (f_inductive - 1.0)
   - resonance: baseShift * f_inductive * (f_resonance - 1.0)
   - anisotropy: baseShift * f_inductive * f_resonance * (f_anisotropy - 1.0)
   - total: number

4.3.5. MODULE 5: IR NORMAL MODE COUPLING
   
   Fonksiyon: detectCoupledModes(modes: VibrationalMode[])
   
   Fermi Resonance Detection:
   - Her mod çifti için:
     - deltaFreq = |freq_i - freq_j|
     - deltaFreq < 50 cm⁻¹ ve intensity > 10 → coupling
     - coupling = exp(-deltaFreq / 20)
     - Intensity redistribution:
       * mode_i.intensity = total * (0.5 + coupling * 0.2)
       * mode_j.intensity = total * (0.5 - coupling * 0.2)
     - Frequency shifts:
       * mode_i.frequency += coupling * 5
       * mode_j.frequency -= coupling * 5

4.3.6. MODULE 6: DYNAMIC SYMMETRY BREAKING
   
   Fonksiyon: analyzeConformerSymmetry(conformers: Conformer[])
   
   İşleyiş:
   1. Her konformer için point group belirlenir
   2. Weighted distribution hesaplanır
   3. Dominant symmetry bulunur

4.3.7. MODULE 7: THROUGH-SPACE MAGNETIC EFFECTS
   
   Fonksiyon: calculateThroughSpaceEffect(atom1Position, atom2Position, magneticMoment)
   
   Formül: effect = (SPACE_SHIELDING_CONSTANT * magneticMoment) / r³
   
   Parametreler:
   - SPACE_SHIELDING_CONSTANT = 10.0 ppm·Å³
   - r = √(dx² + dy² + dz²)
   - Threshold: r > 5.0 Å → effect = 0

4.3.8. MODULE 8: ADVANCED SOLVENT INTERACTION
   
   Fonksiyon: calculateSolventEffect(solvent, functionalGroup, baseShift)
   
   Solvent Properties:
   - CDCl3: {dielectric: 4.8, hbDonor: 0.2, hbAcceptor: 0.0}
   - DMSO-d6: {dielectric: 46.7, hbDonor: 0.0, hbAcceptor: 0.8}
   - D2O: {dielectric: 78.4, hbDonor: 1.0, hbAcceptor: 1.0}
   - MeOD: {dielectric: 32.7, hbDonor: 0.9, hbAcceptor: 0.7}
   - Acetone-d6: {dielectric: 20.7, hbDonor: 0.0, hbAcceptor: 0.5}
   
   Etkiler:
   1. Dielectric: isPolar ? (dielectric - 5) * 0.02 : 0
   2. H-bonding: canHBond ? (hbDonor + hbAcceptor) * 0.5 : 0
   3. Coordination: 0 (placeholder)

4.3.9. MODULE 9: ¹³C DYNAMIC NOE MODEL
   
   Fonksiyon: calculateNOEEnhancement(molecularWeight, temperature, solventViscosity)
   
   Rotational Correlation Time (Stokes-Einstein-Debye):
   τ_c = (4πηr³) / (3kT)
   
   Algoritma:
   1. Molecular radius hesaplanır:
      - density = 1.0 g/cm³
      - volume = MW / (N_A * density)
      - radius = ∛(3V / 4π)
   2. tau_c = (4π * viscosity * r³) / (3 * k_B * T)
   3. omega_C = 2π * 100e6 rad/s (¹³C Larmor frequency)
   4. x = omega_C * tau_c
   5. NOE:
      - x < 1 → noe = 1.988 (extreme narrowing)
      - x ≥ 1 → noe = 1.988 * (1 - x) / (1 + x)
   
   Sabitler:
   - AVOGADRO = 6.02214076e23 mol⁻¹
   - k_boltzmann = R / AVOGADRO

4.3.10. MODULE 10: CROSS-VALIDATION BETWEEN SPECTRA

      - ¹H: 4.0+ ppm, broad
   3. Aromatic consistency:
      - IR: 1450-1600 cm⁻¹ veya 3000-3100 cm⁻¹
      - ¹H: 6.5-8.5 ppm

4.4.1. calculateDihedralAngle(pos1, pos2, pos3, pos4): number

5.1.3. get_metadata() -> Dict

5.1.4. preprocess(lb=0.3, zero_fill_factor=2)
   
   Adım 1: Apodization (Exponential Multiplication)
   
   Formül: S_apod(t) = S(t) · e^(-LB·t)
   
   Algoritma:
   1. Dwell time hesaplanır:
      dwell_time = 1.0 / (spectral_width * spectrometer_freq)
   2. Time array: t = np.arange(len(fid_data)) * dwell_time
   3. Exponential window: exp_window = np.exp(-lb * t)
   4. Apply: fid_data = fid_data * exp_window
   
   Parametreler:
   - lb: Line broadening (Hz), tipik 0.3-1.0
   
   Adım 2: Zero Filling
   
   Algoritma:
   1. Target size: target_size = len(fid_data) * zero_fill_factor
   2. Next power of 2: next_power_of_2 = 2^ceil(log2(target_size))
   3. Zero padding: np.pad(fid_data, (0, next_power_of_2 - len(fid_data)), mode='constant')

5.1.5. fourier_transform()
   
   Fast Fourier Transform: Time Domain → Frequency Domain
   
   Formül: S(ω) = Σ S(t)e^(-iωt)
   
   Algoritma:
   1. FFT: spectrum = np.fft.fft(fid_data)
   2. Zero frequency shift: spectrum = np.fft.fftshift(spectrum)
   3. Magnitude: spectrum = np.real(spectrum)
   4. PPM scale oluşturulur:
      ppm_scale = np.linspace(sw_ppm, 0, n_points)
   
   Dönen Değerler:
   - self.spectrum: np.ndarray
   - self.ppm_scale: np.ndarray

5.1.6. phase_correction(ph0=0.0, ph1=0.0, auto=True)
   
   Phase Correction: S_corr(ω) = S(ω) · e^(i(φ₀ + φ₁·ω))
   
   Parametreler:
   - ph0: 0th order phase (frequency-independent, degrees)
   - ph1: 1st order phase (frequency-dependent, degrees)
   - auto: Automatic phase calculation
   
   Auto-Phase Algoritma (Basitleştirilmiş ACME):
   1. Max peak index bulunur: max_idx = argmax(|spectrum|)
   2. ph0 optimizasyonu (-180° to 180°, 100 step):
      - test_spectrum = spectrum * cos(ph0_rad)
      - Peak height maksimize edilir
   3. ph1 = 0 (well-shimmed data için tipik)
   
   Phase Application:
   1. phase = deg2rad(ph0) + deg2rad(ph1) * linspace(-0.5, 0.5, len(spectrum))
   2. spectrum = spectrum * cos(phase) - imag(ifft(spectrum)) * sin(phase)

5.1.7. baseline_correction(poly_order=3)
   
   Algoritma:
   1. Baseline regions tespit edilir:
      - threshold = percentile(|spectrum|, 20)
      - baseline_mask = |spectrum| < threshold
   2. Polynomial fit:
      - x = np.arange(len(spectrum))
      - baseline_points = x[baseline_mask]
      - baseline_values = spectrum[baseline_mask]
      - coeffs = np.polyfit(baseline_points, baseline_values, poly_order)
      - baseline = np.polyval(coeffs, x)
   3. Baseline subtraction: spectrum = spectrum - baseline

5.1.8. detect_peaks(height_threshold=0.05, distance=10)
   
   Algoritma:
   1. Normalization: spectrum_norm = spectrum / max(|spectrum|)
   2. Peak finding: peak_indices, properties = signal.find_peaks(
        spectrum_norm,
        height=height_threshold,
        distance=distance
      )
   3. Her peak için:
      - ppm = ppm_scale[idx]
      - height = spectrum_norm[idx]
      - Integration (basit):
        left = max(0, idx - distance//2)
        right = min(len(spectrum_norm), idx + distance//2)
        area = np.trapz(spectrum_norm[left:right])
   
   Dönen Değer: List[Dict] ({ppm, height, area})

5.1.9. compare_with_theoretical(theoretical_peaks: List[float])
   
   Algoritma:
   1. Detected peaks: detect_peaks()
   2. Tolerance: 0.2 ppm
   3. Her experimental peak için:
      - En yakın theoretical peak bulunur
      - Distance < tolerance → matched
      - Distance ≥ tolerance → unmatched_experimental
   4. Her theoretical peak için:
      - Eşleşme yoksa → missing_theoretical
   
   Dönen Değer:
   {
     'matched_peaks': List[{experimental, theoretical, delta, type}],
     'impurity_peaks': List[{ppm, height, type}],
     'missing_theoretical': List[{ppm, type}],
     'match_rate': float
   }

5.1.10. export_spectrum(output_format='json')

     'intensity': spectrum.tolist(),

   }

6.3. MATEMATİKSEL FORMÜLLER ÖZETİ
-----------------------------------

1. Shoolery Kuralı:
   δ = 0.23 + Σσ(X) + steric

2. Karplus Eşitliği:
   J = A + B·cos(φ) + C·cos²(φ)
   (A=7.0, B=-1.0, C=5.0)

3. Boltzmann Ağırlıklandırma:
   w_i = exp(-E_i / RT) / Σ exp(-E_j / RT)

4. Exchange Regime:
   ratio = k / Δν
   - ratio > 10 → fast
   - ratio < 0.1 → slow
   - 0.1 ≤ ratio ≤ 10 → intermediate

5. AB System (Quantum Mechanical):
   E = ±½√(Δν² + J²)

6. Through-Space Effect:
   effect = (10.0 * μ) / r³

7. NOE Enhancement:
   τ_c = (4πηr³) / (3kT)
   x = ω_C * τ_c
   noe = 1.988 * (1 - x) / (1 + x) [x ≥ 1]

8. FID Apodization:
   S_apod(t) = S(t) · e^(-LB·t)

9. Fourier Transform:
   S(ω) = Σ S(t)e^(-iωt)

10. Phase Correction:
    S_corr(ω) = S(ω) · e^(i(φ₀ + φ₁·ω))

9.6.1. computeAtomCountsFromRDKitAtoms(atoms: GraphAtom[]): Record<string, number>

9.7. NMR PREDICTION

İşleyiş:

      - lockedAtomCounts = graph.atomCounts
      - lockedDBE = graph.dbe
      - lockedTotalH = graph.totalHydrogenFromFormula
   
   2. Deterministic Model (modelPrediction):
      - UltraThink engine çağrılır (varsa)
      - Shoolery kuralları ile chemical shift hesaplanır
      - Karplus eşitliği ile coupling constants (coords3d varsa)
      - Proton gruplama: symmetry class + heavy atom bazlı
      - Multiplicity: n+1 kuralı + coupling path
      - Integration: equivalent proton sayısı
      - modelPrediction.peaks[] doldurulur
   
   3. LLM Interpretation (llmInterpretation):
      - LLM'e YALNIZCA lockedFormula verilir (user input değil)

      - LLM formül türetmesi YASAK

      - llmInterpretation.peaks[] doldurulur
      - source = "llm" etiketi eklenir
   
   4. Final Consensus (finalConsensus):
      - Model ve LLM peak'leri birleştirilir
      - mergePeaksByShift(modelPeaks, llmPeaks, tolPpm=0.2)
      - Her peak için source etiketi: "model" | "llm" | "consensus"
      - method: "model-only" | "llm-only" | "fusion"
   
   5. Drift Detection:
      - LLM response'unda formül kontrolü
      - LLM farklı formül döndürürse: IDENTITY_DRIFT_DETECTED warning
      - LLM peak'leri atılır, sadece model kullanılır

11.2. STRICT PARSING FUNCTIONS
-------------------------------

Dosya: lib/utils/peakParser.ts

11.2.1. parseH1Peaks(text: string): {peaks: H1Peak[], warnings: ParseWarning[]}

   Format: δ 8.13 (d, 2H)
   
   Guardrail Kuralları:
   1. PPM aralığı: -2 ile 15 arası (dışındakiler reject edilir)
   2. "ppm" kelimesi varsa skip (C13 formatı)
   3. Regex: /^δ\s*([+-]?\d+(?:\.\d+)?)\s*\(\s*([A-Za-z]{1,4})\s*,\s*([0-9]+(?:\.[0-9]+)?)\s*H\s*(?:,.*)?\)\s*$/i
   
   Örnek Reject:
   - "δ 3300.00 (o, 1H)" → UNIT_MISMATCH warning, peak rejected
   - "δ 20.00 (s, 1H)" → OUT_OF_RANGE warning, peak rejected

11.2.2. parseC13Peaks(text: string): {peaks: C13Peak[], warnings: ParseWarning[]}

   Format: δ 203.60 ppm (Cq)
   
   Guardrail Kuralları:
   1. PPM aralığı: 0 ile 250 arası (dışındakiler reject edilir)
   2. "ppm" kelimesi veya carbon type (Cq, CH, CH2, CH3) olmalı
   3. Regex: /^δ\s*([+-]?\d+(?:\.\d+)?)\s*(?:ppm)?\s*\(\s*(Cq|CH3|CH2|CH)\s*\)\s*$/i
   
   Örnek Reject:
   - "δ 300.00 ppm (Cq)" → OUT_OF_RANGE warning, peak rejected

11.2.3. parseFTIRBands(text: string): {bands: FTIRBand[], warnings: ParseWarning[]}

   Format: 3300 cm⁻¹ (50)
   
   Guardrail Kuralları:
   1. Wavenumber aralığı: 400 ile 4000 cm⁻¹ arası
   2. "δ" ile başlayan satırlar skip edilir (NMR formatı)
   3. Regex: /^(\d+(?:\.\d+)?)\s*cm\^-1(?:\s*\(\s*(\d+(?:\.\d+)?)\s*\))?\s*$/i
   
   Örnek Reject:
   - "100 cm⁻¹" → OUT_OF_RANGE warning, band rejected
   - "5000 cm⁻¹" → OUT_OF_RANGE warning, band rejected

      - DBE = 1: "1 halka veya 1 çift bağ"
      - DBE ≥ 4: "aromatik/çoklu halka"
   5. Markdown bloğu döndürülür

12.3. DBE POST-PROCESSING
---------------------------

Dosya: lib/hooks/useSpectralAnalysis.ts

AI'ın yazdığı DBE bloğu replace edilir:
```typescript
const effectiveFormula = activeKnownMolecule?.formula ?? result.formula;
const dbeBlock = renderDBEBlock(effectiveFormula);

// Replace AI's DBE section
const dbeSectionRegex = /(\*\*0\.\s*DBE\s*Analizi[^*]*\*\*)/s;
if (dbeSectionRegex.test(result.reasoning)) {
  result.reasoning = result.reasoning.replace(dbeSectionRegex, dbeBlock);
} else {
  // Prepend if not exists
  result.reasoning = dbeBlock + "\n\n" + result.reasoning;
}
```

12.4. FORMULA NORMALIZATION
-----------------------------

Fonksiyon: normalizeToHill(formula: string): string

Desteklenen Formatlar:
   - "C₄₇H₅₁NO₁₄" → "C47H51NO14"
   - "C47H51NO14+" → "C47H51NO14"
   - "C47 H51 N O14" → "C47H51NO14"

12.5. FORMULA VALIDATION
-------------------------

Fonksiyon: formulaEquals(formula1: string, formula2: string): boolean

Algoritma:
   1. Her iki formül normalize edilir
   2. parseFormula() ile atom sayılarına çevrilir
   3. Atom sayıları karşılaştırılır
   4. Tüm elementler için eşitlik kontrol edilir
